Impedance Equation

Z(ω) = Rs + (Rox / (1 + jωRoxCox)) + (1 / (Git + jω(Cd + Cit)))

Where:
• Rs: Series resistance
• Rox || Cox: Oxide bulk
• Cd || Git || Cit: Depletion & interface traps
• ω = 2πf: Angular frequency
